# EMPTYHELL

Browser-first 3D game prototype for the ESCIE universe.

## Visual standard
See `VISUAL-DIRECTION.md`.

**Reality first. ESCIE second. Distortion last.**

## Phase 1 target
LOAD → SPAWN → MOVE → LOOK → INTERACT → PAUSE/MAP → EXIT

## Current prototype
This first foundation establishes:
- fullscreen WebGL renderer
- cinematic cold Montréal-inspired lighting
- winter surface/material language
- residential massing
- railway/fence pressure boundaries
- park anchor
- third-person-style player presentation
- mouse look / movement foundation
- pause overlay
- mobile-safe viewport shell

The geometry is intentionally provisional. It is **not yet a verified reconstruction of Parc-Extension**. Real map/terrain/street data must be verified before production world-building.

## Development rule
Do not scale the world until a small vertical slice looks and feels correct.

## Build verification

GitHub Actions builds the project on pushes and pull requests to `main`.
