# EMPTYHELL — Visual Direction v1.0

## Core sentence
A real Montréal neighbourhood remembered through the eyes of someone who lived there — beautiful, cold, human, damaged, and occasionally distorted.

## Locked hierarchy
1. Real place
2. Material
3. Weather
4. Human detail
5. Light
6. Camera
7. Memory
8. Distortion

## Rules
- Reality first. ESCIE second. Distortion last.
- Stylized realism, not generic cyberpunk or generic horror.
- Montréal-specific architecture and infrastructure.
- Winter is physical: snow, slush, ice, footprints, tire tracks and condensation.
- Blue represents reality/operation.
- Purple represents signal/distortion and remains rare.
- VHS/documentary treatment is contextual, not permanent.
- Physical boundaries should explain traversal limits.
- UI stays minimal; map/pause is the primary 2D interface.
- Audio is geographic and environmental.
- Build a beautiful clean scene before adding distortion.
